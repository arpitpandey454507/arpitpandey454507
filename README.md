> Solution for **Smart India Hackathon 2026** — Problem Statement **SIH26038**.

**✨ Highlights**
- 🎯 **92% accuracy** and **0.90 Quadratic Weighted Kappa** (550-image test set)
- 🧠 EfficientNet-B0 fine-tuned via transfer learning (5-class classification, APTOS 2019)
- 🖼️ Preprocessing: border cropping, CLAHE, ImageNet normalization
- ⚖️ Weighted cross-entropy for class imbalance
- 🔥 Grad-CAM explainability in the inference pipeline
- 📄 FastAPI backend + Streamlit frontend, SQLite history, automated PDF reports
